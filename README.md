# PREMIUM EFFECTS

This is extremely important.

Do not create a static website.

Implement subtle premium interactions throughout the site.

### Cursor

Create a custom cursor interaction on desktop.

Use:

* Small white center dot
* Soft red outer glow
* Cursor expands when hovering links/buttons
* Cursor changes when hovering portfolio cards

### Magnetic buttons

Buttons should subtly move toward the cursor when hovered.

### Scroll reveal

Sections should animate into view using:

* Fade
* Translate Y
* Slight blur-to-sharp transition

Avoid excessive animation.

### Image parallax

Hero and portfolio images should move slightly based on scroll/mouse movement.

### Grain

Add a very subtle film-grain/noise overlay across the website.

It should be barely visible.

### Glow

Use very subtle red radial glows behind important sections.

### Glassmorphism

Use glass effects only where appropriate.

Do not make the entire website glassmorphic.

### Hover effects

Every clickable element should have a meaningful hover state.

# RESPONSIVENESS

The website must be fully responsive.

Desktop:
1440px+

Tablet:
768px–1200px

Mobile:
320px–767px

On mobile:

* Hero becomes single-column
* Image collage rearranges elegantly
* Navigation becomes fullscreen menu
* Services become vertical cards
* Portfolio becomes 1-column
* Stats become 2-column
* CTA becomes vertical
* Contact form becomes single-column

Do NOT simply shrink the desktop layout.

Create a proper mobile composition.
